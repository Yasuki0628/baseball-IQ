BASEBALL IQ オフライン版（PWA）
1. このフォルダの中身を、HTTPSで公開できる場所に置きます（GitHub Pages、Netlify、Cloudflare Pagesなど）。
2. スマホでそのURLを、オンラインで1回開きます。ファイルが端末に保存されます。
3. iPhone：Safariの共有ボタン →「ホーム画面に追加」。Android：メニュー →「ホーム画面に追加／アプリをインストール」。
4. 以降は、電波がなくても、ホーム画面のアイコンから起動できます。
注意：ファイルを更新したら、sw.js の CACHE 名（baseball-iq-v10）を v11 に変えてください。
成績は端末のブラウザ内にだけ保存されます。
